# MR. FOX — барбершоп в Королёве

Адаптивный статический сайт без админ-панели. HTML, CSS, JavaScript; сборка и установка зависимостей не требуются.

## Запуск

```bash
python3 -m http.server 8000 --directory dist
```

Открыть http://localhost:8000. На статическом хостинге корневая директория публикации — `dist`.

## Файлы

- `dist/index.html` — сайт
- `dist/style.css` — оформление и мобильная версия
- `dist/app.js` — категории услуг и цены
- `dist/assets/` — изображения
- `dist/research.html` — исследование и аргументы для презентации владельцу
