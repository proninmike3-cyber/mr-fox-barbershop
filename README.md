# MR. FOX — барбершоп в Королёве

Адаптивный статический сайт без админ-панели: HTML, CSS и JavaScript. Сборка и установка зависимостей не требуются.

## Размещение

Файлы сайта находятся в корне репозитория: `index.html`, `style.css`, `app.js`, папка `assets`. Для обычного хостинга загрузите их в корневую папку сайта (например, `public_html`).

Для GitHub Pages выберите ветку `main` и папку `/ (root)` в настройках Pages. Доступность Pages зависит от тарифа и видимости репозитория; сам репозиторий остаётся приватным.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000.

## Содержимое

- `index.html` — главная страница
- `style.css` — оформление и адаптация для телефона
- `app.js` — категории услуг и цены
- `assets/` — изображения
- `research.html` — исследование компании для презентации владельцу
